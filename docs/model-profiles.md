# 模型档案、验证与配置文件

入口：设置 → 连接与模型 → 自定义 API。供应商与 Key 页面选择一个模型及其归属 Key，展开模型详情；“导入、导出与备份”页管理连接与模型池备份。

## 能力和来源

每个 Key 独立保存模型目录、接口报告（reported）、用户覆盖（overrides）、模型请求参数（request）及验证记录（verification）。目录发现不代表生成或图片能力已经验证。刷新目录更新报告值，保留明确设置的覆盖和请求参数；恢复接口报告值会清空覆盖。覆盖中的 null 表示明确设为未知。

更换凭证会清除原凭证的检测与验证结果；手动配置和导入的模型 ID 保留。修改连接 URL 或协议需重新检测目录。供应商默认档位与 Key 的实际能力分别处理，调度会排除不支持当前档位的 Key。

## 模型请求参数

每个 Key 的每个模型可覆盖连接默认的思考模式、固定预算、思考强度字段、档位映射、Chat 输出上限字段、超时和兼容 JSON。未覆盖则继承旧版连接默认值；选择“服务默认”不额外发送思考开关。协议自动值遵循相应转换器，并非每个协议都支持固定思考预算或自适应模式。具体上游扩展可通过档位映射、强度字段和兼容 JSON 配置，并检查实际请求预览。

档位映射只转换参数，例如 max → high，不证明模型具备对应思考能力。兼容 JSON 不允许修改模型、消息、流式设置等路由或传输保护字段；可以覆盖的标准字段会在预览中标明。编辑 JSON 后先应用到草稿，再保存供应商。

## 显式验证

验证只在点击时请求所选 Key 的所选模型，不使用模型池换线，不自动重试或批量探测，也不会自动保存草稿。

- 文本生成：检查非空文本回复。
- 工具往返：要求调用测试工具并识别合成返回值，最多两次请求，不执行外部工具。
- 图片识别：用本地生成的红、蓝测试图片分别检查，最多两次请求。
- 思考参数：检查该档位请求是否被上游接受，不代表实际推理质量或预算生效。

记录包含时间、状态、耗时和配置签名。连接、凭证、模型参数或报告变化后，旧结果显示待复查；Key 之间不复制结果。探测可能产生上游费用。本地请求预览不发送生成请求，省略认证值并脱敏敏感字段。

## 上下文和工具图片

有声明容量时，运行时把上下文窗口和自动压缩窗口传给 Claude CLI；输出上限也受模型声明限制。模型池取参与线路声明容量的最小值。有容量已知的线路时，不调度容量未知的线路；图片或工具能力筛选后仍保持这条约束。全部未知时使用 CLI 默认值，不能保证上游的实际容量。

本机 Claude CLI 2.1.300 已实际返回 64,000 token 上下文窗口及环境变量来源的自动压缩配置，覆盖三种协议。其他 CLI 版本是否支持这些环境变量需重新验证。能力声明本身不会改变上游真实限制。

工具返回的截图会保留：Responses 使用对应 function_call_output 的图片数组；Chat 在全部 tool 消息之后附带图片及原始工具调用 ID。有图片时优先使用可用的图片线路；明确不支持图片的线路仍可继续聊天，图片块转为本地文件路径引用，保留文本和工具调用关联。真实 CLI 浏览器测试覆盖 Anthropic、Chat、Responses 三种协议的截图回传及源码修改。

## 导出、导入和回滚

供应商内部配置使用 schemaVersion 2，交换文件和备份封套使用版本 1。旧版配置读取兼容，保存时升级；不支持的未来版本拒绝覆盖。

脱敏导出不含 API Key、凭证密文、请求头值、兼容参数 JSON 和验证记录。URL 等普通配置仍在文件中，分享前可查看导出内容。导入按照 ID 合并，保留已有相同 Key ID 的本机凭证和私有兼容配置；新供应商、缺少凭证的 Key、新模型池默认停用。导入不包含的现有供应商和模型池保留。

导入和备份恢复先显示概览与逐字段差异，点击应用后才写入。预览有效期十分钟，期间配置发生变化则拒绝应用，需重新预览。任务运行期间禁止应用；成功后重新建立 CLI 连接。

保存、删除及应用前备份，最多保留三十份，位于 Electron userData 的 provider-backups。备份保留本机加密凭证和私有配置，不是可跨电脑使用的脱敏交换文件；恢复要求原系统用户可解密。备份恢复整份供应商和模型池快照，可能移除快照之后新增的配置。事务日志保护两份配置文件共同更新；失败回滚，启动时发现未完成事务也回滚。界面逐字段差异不展示私有请求头、兼容 JSON 或密钥值。

## 附件与历史图片兼容（2026-10-16）

前端保留图片预览和原始附件，向 CLI 提交附件时只发送本地绝对路径，不主动嵌入图片数据。文件工具是否读取由模型按需决定；本地路径不会让远程上游直接访问磁盘。

浏览器 screenshot 工具将截图保存到 attachments/browser-captures，给模型返回文件路径。用户点击截图或选中修改仍可在聊天草稿中看到图片预览。

若历史消息或文件工具结果包含图片块，明确不支持图片的线路会把图片转为 attachments/image-references 下按内容去重的文件引用；工具调用 ID 和文本结果保留，原会话及附件不修改，界面显示兼容提示。图片 URL 不自动下载。文件路径只表示可按需读取的资源，不代表模型已理解图片；文本模型不能因此获得视觉能力。图片能力未知的线路保持原协议行为，不根据模型名猜测能力。
