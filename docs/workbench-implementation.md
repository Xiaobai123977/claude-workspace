# 工作台实现与验收

2026-10-15。对应 `claude-cli-feature-gap-audit.md` 和 `model-provider-settings-research.md` 的实施。

## 入口和数据

功能按场景分布，不再提供总工作台入口：

- 设置：连接与模型、权限、回复偏好、项目说明与规则、记忆、上下文与历史；原生连接与模型覆盖在“配置来源”中只读查看。
- 输入区：当前聊天的模型与推理强度、权限、聊天运行设置、目标与循环。
- 聊天顶部：任务、文件差异与检查点在侧面板显示，聊天与输入区保留。用户消息提供“回到这里”入口。
- 聊天选项：用量、会话与诊断、导出、原生历史与终端接力。上下文共用同一用量面板。
- 项目右键：隔离工作区的创建和清理；文件差异页保留检查点操作。
- 扩展：插件、Skills、Agents、工作流、MCP、Hooks、Mods、市场。
- 左侧计划任务：应用持久计划单独创建和管理，与当前会话目标/循环分开。

模型接入统一在设置里切换：Claude 订阅 / 自定义 API。自定义连接填写协议、URL 和 API Key 后自动读取目录，支持模型显示勾选、逐模型思考档位与默认强度。启用连接同时应用于当前聊天和新聊天，并清除旧来源模型/思考覆盖；运行中的聊天禁止切换接入。聊天输入区只列出当前来源可见模型及对应档位，不提供来源混选或任意模型 ID。高级选项保留环境变量/免认证、兼容参数、手动模型和能力修正。切换设置分类、页面、聊天和工具面板时保护未保存草稿。

新增主模块：

- `electron/providers.cjs`：连接、加密凭据、草稿模型发现、模型能力、运行配置。
- `electron/provider-proxy.cjs`：仅监听回环地址且需要随机凭证的协议代理。
- `electron/operations.cjs`：文档、Hooks、Mods、Git、原生历史、检查点、终端接力和本地调度。
- `src/ProvidersPage.tsx`：连接表单、模型管理和聊天模型选择。
- `src/Workbench.tsx`：任务、差异、文档、自动化、运行和诊断界面，按需加载。

应用数据目录中新增 `providers.json` 和 `schedules.json`。连接凭证通过 Electron safeStorage 加密；不进入前端快照。模型获取失败不覆盖原列表；手工配置有来源标记，未知能力不自动填成支持。

## 明确边界

- Mod 的行为逻辑可以随 CLI 执行，原生 Mod UI 不会在 `-p` 中绘制，未宣称兼容其面板。静态发现并不等于某个第三方 Mod 已经过行为验收。
- Agent Teams 不通过当前 `-p` 通道创建队友，提供交互终端接力；没有重建原生 Teams 面板。
- Remote Control、云会话、Channels 和 Chrome 受账户、平台及外部安装条件影响。这里只提供接力入口，不宣称其外部服务已登录或通过端到端验收。终端中的后续消息从 CLI 原生 JSONL 自动同步至 GUI；打开已有会话不会重复导入。
- 工作流使用 CLI 的原生执行和任务事件，GUI 提供配置、调用、任务状态与停止；没有复刻原生交互工作流视图的所有暂停/编辑控制。
- 本应用计划需要应用持续运行；关闭应用停止调度，恢复后不会补跑每个错过的时点。每次运行创建独立聊天，使用 dontAsk；未预授权操作会被拒绝。
- `/loop` 使用原生会话调度；查看和清除按钮请求 Claude 调用 Cron 工具，会产生模型用量，并以工具执行结果为准。
- 文件回退只覆盖原生检查点追踪的编辑，无法撤销任意 Shell 或远端操作。对话回退创建分支，保留原记录。
- Git 差异只预览限定大小的内容；全新无提交的仓库需要先创建 HEAD。独立 worktree 从 HEAD 创建，不复制未提交内容。
- 独立连接固定其上游模型，原生 Fast 与备用模型链只对本机继承模式开放。第三方模型列表成功不等于工具或思考能力验证成功。
- 预算与费用是 CLI 估算，不能代替第三方账单。高级兼容参数由用户按目标服务文档配置，未承诺任意 OpenAI 兼容站点完全一致。
- MCP OAuth 登录向导和通用插件 userConfig 表单仍不在本次实现范围，现有扩展管理能力不因此自动获得这两项。

## 入口重构验证

构建、38 项单元测试及聊天、设置、审批、扩展和综合功能 UI 测试通过。综合 UI 额外检查连接页没有执行工具/保存范围、连接草稿切换时可取消离开、运行草稿可阻止打开计划任务、目标与循环不混入本地调度、任务与差异侧面板保留消息输入框。

模型接入重构验证：39 项单元测试通过，覆盖隐藏模型持久化、目录刷新保留和拒绝运行隐藏模型；UI 验证自动获取、模型显示选择、思考档位修正、订阅/自定义互斥、排除其他连接模型、旧思考值清理。已用真实 CLI 对本地模拟上游验证三协议，未调用付费端点。

设置去重：供应商列表是唯一选择入口；旧版 CLI 连接不再提供第二套编辑表单；默认权限仅在权限页配置；思考默认值按模型配置，当前聊天在输入区调整；项目说明和工作流页面仅编辑定义，执行与代理选择回到聊天；配置来源只读展示，并允许显式清除旧版覆盖，保留原有持久数据。
