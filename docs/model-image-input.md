# 模型图片输入偏好

在聊天输入栏的模型选择菜单中设置“接受图片输入”。选择按连接和模型分别保存，Claude 订阅、自定义供应商和模型服务池互相独立，重启后保留。未设置时采用模型已声明的图片能力；未知能力默认接受。

关闭时，下一次请求通过 CLI 的 `--append-system-prompt` 提示当前模型按非多模态模型使用，不要调用工具读取或解析图片，需要时请用户提供文字描述。这是模型行为提示，并不是工具权限拦截。修改后，运行连接的指纹变化，下一次请求重新连接 CLI，并保留原会话历史；重新开启会移除此附加提示。运行回复期间不可修改。

本项不会改变检测到的模型能力、供应商/Key 的路由条件或协议转换。附件预览保留，所有附件仍仅以文件路径文本传入 CLI，不会因开启而主动发送图片字节。

验证：`npm test`，`npm run test:model-image-input-ui`。界面测试使用独立临时配置和本地假 CLI，检查模型切换、持久化、过期保存拒绝，以及实际启动参数中的提示添加与移除，不调用上游。
