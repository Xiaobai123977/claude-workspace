## 保留的相似入口

- 命令菜单、右键菜单、快捷键和常用按钮是同一功能的快捷入口，不各自保存一份设置。
- 持久默认权限与当前聊天权限分别影响新调用的继承和当前会话覆盖，不能合并成一个值。
- 供应商默认参数与当前 Key 的模型参数是继承关系；模型详情明确覆盖范围。模型池跨 ID 映射与单 Key 目录检测也承担不同职责。
- 项目批量归档与单聊天归档作用范围不同；聊天分支与原生文件检查点也不能互相替代。
- 浏览器地址刷新、模型目录重新获取、原生配置重新读取等刷新作用于不同数据源，保留在各自页面。
